# PRISM Updates

This is the public **Update Repository** for proprietary PRISM installers and update packages. It is a binary distribution location, not the PRISM source repository. PRISM source code remains private and is never distributed from this repository.

## Distribution boundary

This repository may contain only approved PRISM release installers, update packages, release notes, checksums, and required public notices. It must never contain:

- PRISM source code;
- signing certificates, private keys, or other signing material;
- GitHub tokens, upload credentials, or other secrets; or
- private operational data.

Canon runtime binaries must not be uploaded until their redistribution rights and required notices have been documented and approved.

## Release boundary

Release candidates are created as **draft GitHub Releases** for authenticated operator inspection. Creating or updating a draft is not **Publication**. Publication is a separate, explicit action by the authorized release operator after the candidate has passed its required checks.

A published release and its assets are readable anonymously from this public repository; PRISM clients do not require or store a GitHub token. Draft releases remain unavailable to anonymous clients.

No PRISM Production Release has been published from this repository during repository provisioning.
